## Overview

[Cosign](https://github.com/sigstore/cosign) is a tool from the [Sigstore](https://www.sigstore.dev/) project used to sign, verify, and store signatures for container images and other artifacts. Signing content artifacts helps establish provenance and integrity across the software supply chain.

Cosign is intended to **replace Docker Content Trust (DCT) signing**. DCT (based on Notary v1) is deprecated, and Cosign provides a modern, keyless, and OCI-native signing workflow going forward.

This guide will cover how Cosign is used to sign and verify Cortex XSOAR/XSIAM content artifacts.
